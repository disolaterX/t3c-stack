# Figure it out

For work no playbook fits.

1. **Restate the goal** in one sentence and the outcome that proves it.
2. **Borrow.** Pick the two playbooks closest to the work. Take the steps
   that apply.
3. **Write the custom playbook** as a numbered list, each step with an exit
   check. Show it to the user in one message if the work is risky or
   public; otherwise start.
4. **Work it** like any other playbook.
5. **If it worked and will recur,** run `t3c-reflect` to propose it as a new
   playbook.
