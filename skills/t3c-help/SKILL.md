# t3c help

Read the playbook and skill tables in
[t3c-mode/SKILL.md](../t3c-mode/SKILL.md) and show them to the user. Then
show the current roster from `~/.t3c/roster.md`, or say it is not set up and
that `t3c-roster` writes it.

Ways to start:

- "t3c, fix <bug>" - runs `t3c-mode`, which picks a playbook.
- "arena: <task>" - same task on several vendors.
- "interrogate this diff" - one round of cross-vendor review.
- "t3c roster" - set or change which model fills each role.
